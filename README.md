- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui, lucide-react
- **3D / Motion:** three.js, @react-three/fiber, @react-three/drei
- **Forms & Data:** react-hook-form, zod, Supabase (contact messages)

## Getting Started

Requires Node.js 18+ and npm.

```sh
npm install
npm run dev
```

The dev server runs at [http://localhost:8080](http://localhost:8080).

### Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
